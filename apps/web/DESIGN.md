# DESIGN.md — agent-console 웹 디자인 규칙

Vercel Geist를 참조 모델로 삼은 데이터 콘솔 규칙. 화면을 새로 만들거나 고칠 때 이 문서를 따른다.
여기 없는 결정은 Geist(vercel.com/geist)의 방향을 따르되, 정한 뒤 이 문서에 적는다.

참조 출처 둘: Geist 문서(토큰 구조, 그레이 용도 매핑)와 getdesign.md의 Vercel 분석(정확한 ink/body/mute/faint
텍스트 사다리, 타이포 위계, 반경). 후자는 마케팅 사이트 분석이라 pill 버튼·메시 그라디언트·카드 그리드·
섹션 밴드는 **가져오지 않았다**. 우리는 콘솔이다.

목적: 표와 숫자가 많은 관찰 화면을 **조용하고 읽기 쉽게**. 장식은 없다. 위계는 색과 간격으로만 만든다.

## 0. 이 문서를 고치는 규칙

Vercel이 자기 design.md를 운영하며 얻은 원칙(vercel.com/blog/how-our-agents-build-on-brand-pages-with-design-md)을 따른다.

- **규칙은 관찰 가능한 문장으로.** "표가 답답하지 않게"가 아니라 "표는 가용 폭을 전부 쓴다". 둘 중 하나만 검사할 수 있다.
  "조용하게", "장식 없이" 같은 말은 방향이고, 실제 규칙은 6절의 금지 목록처럼 눈으로 확인할 수 있는 항목이어야 한다.
- **교정은 강제할 수 있는 가장 좁은 곳에 둔다.** 판단이 필요한 것은 이 문서 산문. 반복되는 스타일은 `globals.css` 클래스.
  기계적으로 확인할 수 있는 것은 `scripts/design-check.sh`(pre-commit에서 돈다). 문서에만 있는 규칙은 어겨도 아무도 모른다.
- **한 번 틀린 걸로 규칙을 만들지 않는다.** 같은 실수가 반복될 때 추가한다. 스크린샷 하나, 리뷰 코멘트 하나는 규칙의 근거가 아니다.
- Geist와 다르게 정한 것은 이유를 한 줄 적는다. 이유가 없으면 다음 사람이 Geist대로 되돌린다.

## 1. 원칙

- **표가 주인공.** 페이지는 제목 한 줄, 요약 한 줄, 표. 카드·박스·그림자로 감싸지 않는다.
- **그레이로 위계, 색은 상태에만.** accent(blue)는 링크와 선택에만. red/amber/green은 상태(에러, 경고, 정상)에만. 장식용 색 금지.
- **숫자는 모노스페이스, 우측 정렬.** 자릿수가 세로로 맞아야 표를 훑을 수 있다.
- **모든 상태를 그린다.** 로딩, 빈 데이터, 서버 다운, 404. 문구는 "무슨 일인지 + 다음에 할 일" 한 문장.
- **라이트·다크 둘 다.** 시스템 설정을 따른다. 토큰만 바꿔서 동작해야 하므로 색은 항상 CSS 변수로 쓴다.

## 2. 토큰

`app/globals.css`의 `:root`와 `[data-theme]` / `prefers-color-scheme`에 정의한다. 컴포넌트는 변수 이름만 쓴다.

### 색 — 표면과 그레이

light 값은 Vercel 실측(getdesign.md 분석). dark 값은 Geist 다크 스케일에 맞춘 근사치.

| 토큰 | 용도 | light | dark |
|---|---|---|---|
| `--canvas` | 페이지 배경 | `#fafafa` | `#0a0a0a` |
| `--elevated` | 코드 블록, 입력, 살짝 뜨는 표면 | `#ffffff` | `#111111` |
| `--well` | 안으로 들어간 면(표 헤더 배경 등) | `#f2f2f2` | `#1a1a1a` |
| `--hover` | 행 hover | `#ebebeb` | `#1f1f1f` |
| `--hairline` | 모든 1px 보더 | `#ebebeb` | `#2e2e2e` |
| `--hairline-strong` | 보더 hover / 포커스 | `#c9c9c9` | `#454545` |

### 색 — 텍스트 사다리 (4단계, 이 순서로만 내려간다)

| 토큰 | 용도 | light | dark |
|---|---|---|---|
| `--ink` | 제목, 강조 숫자, 본문 최고 대비 | `#171717` | `#ededed` |
| `--body` | 기본 본문, 표 셀, nav 링크 | `#4d4d4d` | `#a1a1a1` |
| `--mute` | 표 헤더, 보조 설명, 메타 | `#8f8f8f` | `#8f8f8f` |
| `--faint` | 비활성, placeholder | `#a1a1a1` | `#666666` |

본문에 순수 검정(`#000`)을 쓰지 않는다. ink는 `#171717`이다.

### 색 — accent와 상태

| 토큰 | 용도 | light | dark |
|---|---|---|---|
| `--link` | 링크, 선택, 막대 | `#0070f3` | `#0072f5` |
| `--link-deep` | 링크 hover / 눌림 | `#0761d1` | `#52a8ff` |
| `--link-soft` | 선택 행 배경, 링크 포커스 링 | `#d3e5ff` | `#10233d` |
| `--error` | 에러, 실패, 느린 요청 텍스트 | `#ee0000` | `#ff6166` |
| `--error-deep` | 에러 강조 / 눌림 | `#c50000` | `#e5484d` |
| `--warning` | 경고 아이콘·막대 | `#f5a623` | `#f5a623` |
| `--warning-deep` | 경고 문구(텍스트 대비용) | `#ab570a` | `#ffc553` |
| `--warning-soft` | 경고 배경 | `#ffefcf` | `#3d2a05` |
| `--success` | 정상, 성공 | `#45a557` | `#62c073` |

Vercel 마케팅 사이트는 성공 색을 blue로 겸용한다. 우리는 상태 표가 많아 green을 따로 둔다.

### 타이포

- 본문: **Geist Sans** (`geist/font/sans`). 폴백 `Inter, system-ui`.
- 숫자·ID·코드·경로·시각·섹션 라벨: **Geist Mono** (`geist/font/mono`). 폴백 `ui-monospace, Menlo`. 표의 숫자 열은 예외 없이 Mono.
  - Vercel design.md는 반대다: 숫자·금액·날짜도 Sans + `tabular-nums`, Mono는 코드·경로·타임스탬프·ID만. 그건 리포트 문서 기준이다.
    우리 표는 한 행에 ID·시각·토큰 수·비용이 섞여 있어, 데이터 열을 Mono 하나로 묶는 쪽이 Sans/Mono가 열마다 번갈아 나오는 것보다 조용하다.
- 굵기는 셋뿐: 제목 600, 라벨 500, 나머지 400. light·black·italic 없음.
- 위계 (크기 / 굵기 / 행간 / 자간):

| 토큰 | 값 | 용도 |
|---|---|---|
| `heading` | 20px / 600 / 28px / -0.4px | 페이지 제목 h1 |
| `eyebrow` | 12px / 500 / 16px / 0, **Mono, 대문자** | 섹션 라벨 h2 ("REPOS", "SKILLS") |
| `label` | 14px / 500 / 20px / -0.28px | 강조 라벨, 현재 nav 항목 |
| `body` | 14px / 400 / 20px / 0 | 본문, 표 셀, nav 링크 |
| `caption` | 12px / 400 / 16px / 0 | 표 헤더, 보조 설명, 메타 |
| `code` | 14px / 400 / 20px / 0, Mono | 코드, 경로, 에러 메시지 |

- 큰 제목일수록 자간을 좁힌다. 20px에서 -0.4px. 본문은 0.
- 숫자에는 `font-variant-numeric: tabular-nums`.
- `eyebrow`의 대문자 Mono도 Vercel design.md가 금지하는 것("all-caps eyebrow, overline")이다. 그건 읽는 문서의 소제목 얘기다.
  여기서 h2는 문장이 아니라 표 이름표("REPOS", "SKILLS")고, 표 헤더(소문자 caption)와 한 번에 구별돼야 한다. 문장형 h2가 생기면 다시 판단한다.

### 간격·형태

- 간격 스케일 4 기반: `4 8 12 16 24 32 40 64`. 페이지 좌우 패딩 24, 섹션 사이 40, 제목과 요약 사이 8.
- 콘텐츠 최대 폭 1200px, 가운데 정렬. 표는 그 안에서 `overflow-x: auto`.
- 반경은 6px 하나. 기능 UI(버튼, 입력, 코드 블록)용. pill·원형·12px 이상 반경은 쓰지 않는다.
- 보더 1px `--hairline`. 깊이는 보더로만 만든다. 그림자 없음. 꼭 떠야 하는 표면(툴팁)만 `0 1px 1px rgba(0,0,0,.04)`.

## 3. 페이지 뼈대

```
<Nav>                      ← 상단 고정 아님. 아래 hairline. 현재 페이지는 label --ink, 나머지 body --body
<h1>제목</h1>              ← heading --ink. 필요하면 " · 부제" 를 --mute로
<p class="summary">…</p>   ← 한 줄 요약, caption --mute. 핵심 숫자는 Mono --ink
<section>                  ← 표 하나. 여러 개면 h2 eyebrow(Mono 대문자 --mute)로 구분
```

## 4. 표

- `<table>` 그대로 쓴다. 헤더는 caption, `--mute`, 소문자, 아래 보더 1px `--hairline`.
- 행 높이 36px, 셀 패딩 `0 12px`. 행 사이 보더 1px `--hairline`. hover 시 `--hover`.
- 셀 텍스트는 `--body`. 첫 열(이름·식별자)만 `--ink`.
- 숫자 열: 헤더와 셀 모두 우측 정렬, Mono, `tabular-nums`. 천 단위 콤마. 돈은 `$` 붙이고 소수 2자리.
- 같은 열은 같은 정밀도. `1.2`와 `1.25`를 한 열에 섞지 않고, 정수로 충분한 값에 소수를 붙이지 않는다. 자릿수가 정보처럼 보이면 가짜 정밀도다.
- 표는 가용 폭을 전부 쓴다(`width: 100%`). 옆 열에 빈 폭이 남는데 이름 열이 줄바꿈되면 폭 배분이 틀린 것이다. 이름을 자르지 말고 열 폭을 고친다.
- 시각: 목록에서는 날짜(`2026-09-03`), 상세에서는 시각(`14:02:31`). 둘 다 Mono.
- ID는 앞 8자만, Mono, 링크.
- 강조 행(느린 요청 등)은 텍스트를 `--error`로. 배경색을 칠하지 않는다.
- 막대(비율 표현)는 높이 8px, `--link`, 라운드 2px, 셀 폭 160px. 축·눈금 없음.

### 행렬 표 (항목 × 기간)

- 행은 항목(스킬), 열은 기간(주). 열 헤더는 `MM-DD` Mono. 마지막 열에 total.
- 0인 칸은 숫자 대신 `·`를 `--faint`로. 빈 자리임을 보이되 시선을 끌지 않는다.
- 색 농도(히트맵)는 쓰지 않는다. 숫자를 읽는 표다.

### 막대 차트 (시계열)

- 높이 120px, 막대 사이 4px, 아래 hairline 하나가 x축. y축·눈금 없음. 최댓값만 우상단 caption Mono.
- 막대 `--link`, 값 0인 날은 `--hairline`(빈 날임을 보여주되 시선을 끌지 않음). hover는 `--link-deep`.
- x 라벨은 월요일에만, `MM-DD` Mono caption. 상세 값은 `title` 툴팁으로.
- 차트 위 요약 줄에 비교 숫자(최근 7일 vs 그 전 7일)를 둔다. 차트는 모양, 숫자는 요약 줄이 말한다.

## 5. 상태

| 상태 | 표현 |
|---|---|
| 로딩 | 서버 컴포넌트라 대부분 없음. 클라이언트 갱신 중이면 요약 줄 끝에 `--faint` 점 하나 |
| 빈 데이터 | 표 자리에 `--mute` 한 문장: "아직 데이터가 없어요. `pnpm ingest` 를 실행하세요." |
| 서버 다운 | `--error` 한 문장 + 원인(에러 메시지)을 code `--mute`로 그 아래 |
| 404 | 제목 "없는 세션이에요", 목록으로 가는 링크 |

문구 톤: 해요체, 한 문장, 다음 행동을 포함.

## 6. 하지 않는 것

- 카드, 그림자, 그라디언트, 아이콘 장식. pill 버튼. Vercel 홈의 메시 그라디언트는 마케팅용이다.
- Tailwind, 컴포넌트 라이브러리. 필요해지면 이 문서를 먼저 고친다.
- 숫자 열에 Sans. 배경색으로 행 강조. accent를 큰 면에 칠하기.
- 텍스트 사다리 건너뛰기(ink → body → mute → faint 순서 밖의 회색 임의 사용).
- 반응형 레이아웃 변환. 좁으면 표가 가로 스크롤한다. 이 콘솔은 데스크톱용이다.

## 7. 구현 방식

- 전역 CSS 하나(`app/globals.css`)에 토큰과 표·nav·상태 클래스. 컴포넌트는 클래스 이름만 쓴다.
- 인라인 스타일은 데이터에 따라 바뀌는 값(막대 폭·높이)에만. 즉 `className="bar"` 요소에만.
- 색은 절대 hex를 컴포넌트에 쓰지 않는다. 변수만.
- 위 두 줄은 `pnpm design:check`가 검사한다. `apps/web/app/**/*.tsx`가 스테이징되면 pre-commit이 자동으로 돈다.

### 클래스 목록

컴포넌트가 쓸 수 있는 클래스 전부. 여기 없는 스타일이 필요하면 `globals.css`에 클래스를 추가하고 이 표에 적는다.
새 클래스를 만들기 전에 아래에서 같은 뜻의 것이 있는지 먼저 본다.

| 클래스 | 붙이는 곳 | 뜻 |
|---|---|---|
| `.page` | 페이지 최상위 div | 최대 폭 1200, 좌우 패딩 24 |
| `.nav` | 상단 `<nav>` | 아래 hairline. 현재 항목은 `aria-current="page"`로 표시 |
| `.summary` | h1 아래 `<p>` | 한 줄 요약. 핵심 숫자는 `<strong>`(Mono, ink) |
| `.sub` | h1 안 `<span>` | " · 부제". mute, 400 |
| `.mono` | 인라인 텍스트 | ID·경로 등 Mono로. 숫자 열은 `.num`을 쓴다 |
| `.table-wrap` | `<table>`을 감싸는 div | 좁을 때 가로 스크롤 |
| `.num` | `<th>`, `<td>` | 숫자 열: 우측 정렬, Mono, tabular-nums |
| `tr.is-error` | `<tr>` | 강조 행. 텍스트 전체 `--error` |
| `td.wrap` | 문장이 들어가는 `<td>` | nowrap 해제, 최대 폭 480, 세로 패딩 8. 질문처럼 문장인 열에만. 짧은 라벨 열은 그대로 nowrap |
| `.status-warning` | 셀 안 텍스트 | 경고 한 단계 아래 신호(quiet 등). `--warning-deep` |
| `.cell-zero` | 행렬 표 `<td>` | 0인 칸의 `·`. `--faint` |
| `.bar-cell` | `<td>` | 막대가 들어가는 셀, 폭 160 |
| `.bar` | `<div>` | 비율 막대. 폭·높이만 인라인 style 허용 |
| `.state` | 표 자리 `<p>` | 빈 데이터 문장. `--mute` |
| `.state-error` | 표 자리 `<p>` | 서버 다운 문장. `--error`. 바로 뒤 `<pre>`에 원인 |
| `.chart` | 차트 컨테이너 | 시계열 막대 차트, 높이 120 |
| `.chart-col` | `.chart` 안 열 | 하루 한 열. 0인 날은 `.is-zero` 추가 |
| `.chart-label` | `.chart-col` 안 | x 라벨(`MM-DD`), 월요일에만 |
| `.chart-max` | `.chart` 안 | 우상단 최댓값 caption |

`h1`, `h2`, `table`, `th`, `td`, `code`, `a`는 태그 자체에 스타일이 있어 클래스가 필요 없다.
